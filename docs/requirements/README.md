# Wymagania

Miejsce na wymagania systemowe oraz wymagania ECU, HMI i aplikacji Windows.

Na tym etapie wymagania SYS-001–SYS-118 znajdują się w [zakresie systemu](../01-zakres-systemu.md). Przy rozbudowie przenosimy je tutaj, zachowując identyfikatory i aktualizując odsyłacze; nie utrzymujemy dwóch niezależnych rejestrów.

Wymaganie szczegółowe powinno mieć identyfikator, jednoznaczną treść, źródło, status oraz kryterium i sposób weryfikacji. Parametry nieustalone oznaczamy wprost jako do ustalenia.

Robocza [mapa obszarów i otwartych tematów](pokrycie-funkcjonalne.md) służy do kontroli zakresu pytań i przeglądów. [Model współpracy](../00-proces-i-status.md) określa podział pracy i podstawę pytań.

F01 zamknięty po [kontroli właściciela](f01-podsumowanie-kontrolne.md); aktywny pakiet: **F02**. F03–F08 oczekują. Pakiety zamykamy kolejno. Domknięcie zakresu funkcjonalnego prowadzimy według [8 pakietów F01–F08](domkniecie-zakresu-funkcjonalnego.md) i bramki G0 ze [ścieżki projektu](../00-proces-i-status.md). Otwarte parametry realizacji rozwijamy w etapach architektury i projektu wykonawczego.

[Macierz SYS → blok → grupa weryfikacji](../verification/macierz-wymagan.md) zawiera pierwszy przydział wszystkich 118 wymagań. Przydział i zatwierdzenie treści są odrębne od późniejszego potwierdzenia na produkcie.
