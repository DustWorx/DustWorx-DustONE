# Weryfikacja

Miejsce na plan weryfikacji wymagań, opisy stanowisk, procedury oraz raporty z prób.

Dla próby zapisujemy co najmniej: powiązane wymagania, badaną rewizję sprzętu i oprogramowania, warunki, kryterium zaliczenia, wynik i odsyłacze do dowodów.

Stan: plan nie został jeszcze opracowany; nie wykonano prób produktu. Kod testów i dane wejściowe obejmujące wiele komponentów należą do `tests/`.
