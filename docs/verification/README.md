# Weryfikacja

Miejsce na plan weryfikacji wymagań, opisy stanowisk, procedury oraz raporty z prób.

Dla próby zapisujemy co najmniej: powiązane wymagania, badaną rewizję sprzętu i oprogramowania, warunki, kryterium zaliczenia, wynik i odsyłacze do dowodów.

Stan: przygotowano [wstępny plan inwentaryzacji Bety Racing 2015](beta-2015-plan-inwentaryzacji.md) z listą dostępnych przyrządów: multimetr, Rigol DHO804, 4 sondy PVP3150 i 3 sondy P4100. Model multimetru i dokumentacja P4100 pozostają do określenia. Nie wykonano pomiarów ani prób produktu; plan pełnej weryfikacji wymagań pozostaje do opracowania. Kod testów i dane wejściowe obejmujące wiele komponentów należą do `tests/`.
