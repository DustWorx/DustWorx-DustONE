# Decyzje projektowe

## Ustalenia organizacyjne

Właściciel projektu wskazał `DustWorx/DustWorx-DustONE` jako repozytorium dokumentacji i wymaga uporządkowanej struktury katalogów. Potwierdzenie: rozmowa projektowa z 2026-10-15.

## Kolejne decyzje

Istotne decyzje zapisujemy w plikach `adr-001-krotki-temat.md`, z kolejnym wolnym numerem.

Minimalna treść:
- data i status: proponowana / zatwierdzona / zastąpiona;
- problem i rozważane opcje;
- decyzja i uzasadnienie;
- skutki, powiązane wymagania i podstawa zatwierdzenia.

Nie tworzymy osobnych zapisów dla drobnych zmian redakcyjnych. Nie ma jeszcze zatwierdzonych decyzji technicznych.
