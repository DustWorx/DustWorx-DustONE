## Kolejne decyzje

Istotne decyzje zapisujemy w plikach `adr-001-krotki-temat.md`, z kolejnym wolnym numerem.

Minimalna treść:
- data i status: proponowana / zatwierdzona / zastąpiona;
- problem i rozważane opcje;
- decyzja i uzasadnienie;
- skutki, powiązane wymagania i podstawa zatwierdzenia.

Nie tworzymy osobnych zapisów dla drobnych zmian redakcyjnych. Zakres zatwierdzonych decyzji wskazuje rejestr powyżej; niezatwierdzone rozwiązania i konwersje zachowują jawny status.
