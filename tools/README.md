# Narzędzia projektu

Miejsce na skrypty do generowania plików, kontroli dokumentacji, przygotowywania wydań oraz obsługi stanowisk projektowych.

Każde narzędzie powinno mieć opis użycia i zależności. Stan: brak narzędzi.

Funkcje rozwojowe przeznaczone do wspólnej aplikacji Windows są częścią `software/windows/`; ten katalog zawiera pomocnicze narzędzia projektu.
