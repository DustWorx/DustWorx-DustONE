# Mechanika

Miejsce na modele obudów i mocowań ECU/HMI, rysunki, uszczelnienia oraz wymagania montażowe.

Pliki edytowalne przechowujemy razem z kontrolowanymi eksportami, gdy są potrzebne do przeglądu lub wykonania części. Narzędzie CAD, materiały, gabaryty i wymagania środowiskowe pozostają do ustalenia.
